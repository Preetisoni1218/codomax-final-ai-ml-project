# AI Student Performance Predictor & Study Assistant 🤖📚

An AI and Machine Learning project that combines a Machine Learning model with Google Gemini AI to create a student performance and study assistance system.

## 🚀 Features

### Machine Learning

The ML model predicts student performance using:

- Study Hours
- Attendance
- Previous Marks
- Assignment Score

### Gemini AI Study Assistant

The AI assistant generates:

- Simple Explanation
- 5 Key Points
- Short Summary
- 3 Practice Questions
- One Study Tip

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Decision Tree Classifier
- Google Gemini API
- Google Gen AI SDK
## 🔄 How It Works

```text
Student Details
      ↓
Machine Learning Model
      ↓
Performance Prediction
      ↓
Enter Study Topic
      ↓
Google Gemini AI
      ↓
Study Material
